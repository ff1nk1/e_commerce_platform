# ADR 0005. Downstream не проверяет JWT

## Контекст

После gateway запрос уже внутри Docker-сети. Повторять проверку подписи в каждом сервисе значит тащить `JWT_SECRET` повсюду.

## Решение

Сервисы доверяют периметру. Клиентские заказы и чат получают `user_id` из JWT, его подставляет gateway, тело клиента не решает, чей это заказ.

Админский JSON каталога и Filament дополнительно требуют `X-User-Id` и `X-User-Role: admin`. Эти заголовки ставит gateway из токена. Клиентские `X-User-*` JSON-прокси не пересылает.

## Почему так

Утечка порта сервиса в сеть всё ещё опасна, но секрет логина один. Каталог не пускает админский CRUD без заголовков, даже если кто-то дернул его из mesh напрямую.

## Что отклонили

Общий JWT-секрет во всех `.env` и приём `X-User-Role` от браузера как есть.
